# Photon Rubber-Ball Research

Physics research on a **photon-sized rubber ball**: r = 275 nm, E = 50 MPa,
nu = 0.5, mass 9.6e-17 kg. What happens when a 1 m/s impact, a Mie-scattering
beam, thermal motion, and relativistic recoil all act on one solid object at
intermediate (5-100) micron-Hertz scales? The folder contains the working
science (code + verified numbers), a **generated narrative corpus** (docs,
HTML, PDFs), the tooling used to produce it, and a complete audit trail —
everything independently re-verified, discrepancies cataloged, no silent fixes.

> **Read `PROJECT_INDEX.md` first.** It is the canonical map: which files are
> `[VERIFIED]` (trust), which are `[NARRATIVE]` (generated prose), and how the
> stewardship rules work.

## What to trust (verified foundation)

The canonical numbers are reproducible with a single command:

```bash
python results_of_record.py      # 16 checks, exit 0
```

The "comparable energies" abstract claim is **false** (~37 orders of magnitude
apart; see `CORRIGENDUM.md` entry 1 and `energy_comparability_probe.py`). What
survives as genuinely coincident: per-photon recoil KE ~ ball zeropoint (9.9x),
JKR adhesion >> kT (6.3e5x), and the trap contraction 0.22 nm = 6.4x the trap
thermal RMS. The 18-script battery runs green under
`python -W error::RuntimeWarning`; the lint standard is `ruff --select F` clean.
